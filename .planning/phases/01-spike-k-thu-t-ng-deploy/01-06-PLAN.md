## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local build → VPS filesystem (root) | Remote scripts run as root under /srv/sites |
| site reload → shared doibung Caddy | A bad site file affects every site on that Caddy |
| public internet → static site | Anyone can request any path under breaktime.doibung.com |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06-01 | Tampering / DoS | release.sh cleanup | mitigate | Hardcoded BASE with `${BASE:?}`; names ^[0-9a-f]{7,40}$; `realpath -e` + dirname equality; never current; `rm -rf --one-file-system --`; list from Vitest-tested selectReleasesToDelete |
| T-01-06-02 | Tampering | half-extracted or concurrent deploy | mitigate | .incoming-<sha> + index.html check, `mv -T` and atomic symlink swap, `flock -n`, abort removes incoming |
| T-01-06-03 | Denial of service | Caddy reload breaks doibung.com | mitigate | `caddy validate` before swap; restore .bak + reload on failure; admin config re-read after reload |
| T-01-06-04 | Information disclosure | .map/.env/dotfiles in web root | mitigate | size gate fails on .map/.env*; Caddy `hide .* *.map` |
| T-01-06-05 | Tampering | command injection via sha/names | mitigate | validateSha locally; names re-validated remotely |
| T-01-06-06 | Denial of service | CPU exhaustion by on-the-fly compression on 1 vCPU | mitigate | br/gz sidecars generated locally; `encode` only as fallback |
| T-01-06-07 | Spoofing | clickjacking of the test build | mitigate | X-Frame-Options SAMEORIGIN |
</threat_model>
