## Phase Goal

**As a** solo operator play-testing on my two reference phones, **I want to** open https://breaktime.doibung.com, walk a low-poly office, slap NPCs into ragdolls and smash 20+ objects in a build that any commit can deploy with one command, **so that** I have measured proof that Three.js + Rapier meets the size, fps and iOS-stability budget before any gameplay phase builds on it.

<objective>
Walking-skeleton slice 1b: the locked stack boots end to end in a real browser — capability gate → weighted loading bar → "Chơi" gate → three.js render loop with a Rapier world stepping a falling box — and unsupported browsers get a readable screen.

Purpose: proves three r186 + Rapier SIMD/compat run under the CSP from 01-01 and establishes the loop, load-task and gesture contracts every later slice uses.
Output: boot modules, physics/render/loop, 2 unit test files, smoke and unsupported e2e specs.
</objective>
